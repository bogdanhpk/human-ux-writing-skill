# Human UX Writing

Скилл для ясных текстов на русском и английском: интерфейсы, ошибки, подсказки, инструкции и техническая документация.

## Использование

В Codex вызовите `$human-ux-writing` и передайте текст или опишите задачу. Скилл сохраняет смысл и факты, учитывает контекст и помогает убрать канцелярит и лишний жаргон.

## Установка в Codex

Попросите Codex установить скилл:

```text
$skill-installer установи https://github.com/bogdanhpk/human-ux-writing-skill в папку human-ux-writing
```

Для ручной установки скопируйте `SKILL.md`, `agents/` и `references/` в `~/.codex/skills/human-ux-writing/`.

## Обновления

Актуальная версия находится в ветке `main`. Автоматическая синхронизация настраивается отдельно на компьютере пользователя; обычная установка через skill-installer создаёт локальную копию.

## Состав

- `SKILL.md` — основной порядок работы.
- `agents/openai.yaml` — название и подсказка для Codex.
- `references/` — рекомендации для русских текстов, микрокопи, технических материалов и редактирования AI-текстов.
